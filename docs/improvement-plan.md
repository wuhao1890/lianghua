## 阶段二：严重缺失（必须补）

### 2.1 预警通知系统
- 后端：预警CRUD API（增删改查 + 价格检查）
- 前端：预警管理页面（列表/新建/删除/开关）
- 通知：弹窗 + 声音提醒

### 2.2 风险管理
- 后端：风控设置API + 风控检查API
- 前端：风控设置页面 + 交易时风控校验
- 核心功能：单笔最大金额限制、日亏损熔断、最大回撤监控

### 2.3 止损单支持
- 后端：订单增加止损价/止盈价字段 + 价格触发检查
- 前端：交易面板增加止损止盈输入

### 2.4 模拟交易（Paper Trading）
- 后端：切换模式API + 模拟账户 + 虚拟资金100万
- 前端：切换开关 + 模拟模式标识

## 阶段三：重要缺失（建议补）

### 3.1 选股筛选器
- 后端：筛选API（价格/涨跌幅/成交量/关键字/排序/分页）
- 前端：筛选页面（条件表单 + 结果表格 + 分页 + 跳转详情）

### 3.2 投资组合增强
- 前端：Analysis页面增加回撤曲线图、月度收益分布图、夏普比率/最大回撤/年化收益指标卡
- 数据：基于交易记录计算

### 3.3 策略回测引擎
- 基于已有 stock_daily 日K数据
- 后端：回测API（选择股票+策略+周期，返回收益曲线/胜率/最大回撤）
- 前端：回测页面（参数配置 + 结果图表）
